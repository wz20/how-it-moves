# Provenance and scope
- Skill instructions, scripts, the vector drawing runtime, jointed mascot, tool machine and demo scene are authored for this package and released under MIT.
- The requested creator reference is an aesthetic comparison, not affiliation, sponsorship or a licence to redistribute the creator's assets. No creator video frames, avatars, music or watermarks are included.
- A preliminary image-generation attempt returned an unsuitable flattened storyboard. It is recorded as rejected in the demo ledger and is not included in the published runtime/assets/video.
- The example uses no private user photos, no 花卷 mascot, no prior knowledge-house images, no external API calls, no hidden models and no font files.
- Fonts are supplied by the operating system; install a properly licensed CJK font yourself. Browser/FFmpeg/Playwright licences are separate from this package. No binaries are bundled.
- Renders of the bundled original vector scene are covered by this package's MIT licence; third-party assets added by users must have their own provenance and appropriate permissions.
