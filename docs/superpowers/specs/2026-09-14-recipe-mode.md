# Explain Motion v0.2 — approved recipe-mode upgrade

## Scope
The user approved default recipe mode plus the existing advanced free-authoring mode, three mechanism recipes, preservation of the original HTML demo, and public GitHub publication under their own account. Repository name: explain-motion. No existing remote repository is to be overwritten.

## Contract
- Models choose a mechanism and edit a small JSON content document, not coordinates, easing, Canvas code, or frame timing.
- Three executable mechanisms: feedback-retry, retrieval-evidence, cache-aside.
- A strict compiler supplies layouts, temporal dependencies, semantic effects, captions, provenance, and the final reading hold.
- Playback and semantic checking consume the same compiled event list; ends are exclusive and side effects occur on arrival/completion.
- Recipe mode is intentionally bounded: 16:9, 1920×1080, 30/60fps, silent, comic-lab. Unsupported ratios/styles must fail explicitly, not silently stretch.
- Advanced authoring and original docs/index.html remain intact.
- Local schema, unit, browser, deterministic-seek, decode, and release checks are distinct from model/learner evaluation; do not fabricate the latter.
- No API keys, font files, creator IP, personal photographs or browser binaries in the public package.
- GitHub publication requires a real write-capable connection. If unavailable, provide a complete checked release and state the blocker.
