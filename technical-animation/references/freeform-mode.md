# 高级自由模式 / Freeform Mode

**用动作解释因果，不是给文字配动效。** 制作通用技术解说，不绑定某个作者、角色、模型、品牌、中文语言或单一选题。

本页保留 v0.1 的自由创作路径；默认请先使用 [配方模式](recipe-mode.md)。只有机制不匹配，或用户明确要求自定义时才走本页。

## 开始
读取 [工作流](workflow.md)、[视觉与素材](visual-system.md)、[动画语法](motion-language.md)。执行前检查现有工程、用户参考、时长、声音需求、可用工具与预算。已有答案不重复问。

浏览器预览遵守 [Skill 的浏览器回退规则](../SKILL.md#浏览器回退)：Chrome 首次失败或授权阻塞就直接切换 ChatGPT／Codex 内置浏览器。先验证内置浏览器的预览能力，逐帧导出另做能力检查。

用户明确要求自动制作时使用 `auto`：合理默认并记录假设，不逐步打断。`guided` 则在内容、样式样张、动态样片三个节点确认。发布到外部平台、付费调用或覆盖用户文件仍需要相应授权。

10 秒默认：**只教一个机制；1920×1080、60fps、无配音；开头直接展示任务；结尾至少 1.5 秒停留。** 时长不够就删知识点，不堆小字。

## 执行契约
1. **语义先行**：写 `brief.md`、`semantic-map.json`。明确实体、输入、状态变化、结果、下一步与停止条件；核验技术主张，标出简化/模拟。Agent 不等于单独一个机器人，不把上下文更新画成训练模型。
2. **动作翻译**：制作 `storyboard.md` 与 `project.json`。每个主动作必须写清“谁触发、传递什么、抵达后谁改变”。结果不能早于调用到达。数据包不能凭空复制或消失。
3. **视觉系统**：先写 `DESIGN.md`，选择原创角色、统一粗线、有限语义色、分层道具。不要克隆创作者标识或从他人视频抠素材。参考只转译视觉语言。按需调用真实生图工具；指定生图失败须如实报告，禁止把旧图拼贴称为新生成。
4. **先静后动**：渲染关键帧检查排版，再做 2—4 秒动作测试。使用可寻帧动画：预备动作→运动→接触→响应→停留；头/手/表情/道具分开控制。边和数据流按时序揭示，不一次显示完整图。
5. **逐帧合成**：优先复用 `runtime/` 的缓动、贝塞尔路径、消息传输、关节角色与绘图函数。根据主题重写场景，不只把 Agent 标签换成 RAG。已有 Remotion/GSAP 工程可适配；不强行迁移。
6. **验收返工**：运行语义验证、单元测试、渲染和完整解码；检查关键帧及过渡帧。按 [审片表](review.md) 记录已验证/未验证内容。失败只改受影响段落，不覆盖批准版本。
7. **交付**：MP4、可修改工程、离线 HTML 预览、来源/素材记录、QA JSON、README。用户要压缩包时再打包。没有实际渲染/检查就不能称“生成成功/通过”。

## 工具入口
从本 Skill 根目录运行，`python` 指向 Python 3.10+。

```bash
python scripts/new_project.py --topic "RAG 为什么先检索再回答" --out /path/to/new-project
# 完成新项目的语义、分镜与 scene.mjs 后：
python scripts/validate.py /path/to/new-project
python scripts/render.py /path/to/new-project --out /path/to/output.mp4
```

初始化只是骨架，不是通用文本转视频模型。**宿主 Agent 负责理解新主题、设计素材和编写动画**；脚本负责确定性渲染与可验证检查。无生图接口时，用户允许的原创矢量方案仍可工作；不可宣称调用了并不存在的接口。

## 硬性质量线
- 无声也应能辨认动作和回传；颜色还要配方向、形状或标签。
- 同时最多三个视觉焦点；关键句默认 ≤14 个汉字，次级内容不过量。
- `call → result → decision` 与停止条件必须可见；教学主线优先于装饰。
- 不使用循环漂浮、全元素弹跳、随机相机或长时间整图缩放冒充讲解。
- 数据跨实体传输用线性/对称缓动；抵达后才能触发工具状态。弹簧用于角色/道具，不用于倒退数据。
- 新比例重新构图；不能把合集裁开或拉伸成独立画幅。
- 保存输入、事件表与已确认素材；反馈只更新相应资产/镜头与审片记录。
