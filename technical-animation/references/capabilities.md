# v0.8 能力矩阵与边界

| 层面 | 当前可执行能力 | 不应声称 |
|---|---|---|
| 规划 | 无图片阶段的有限离散状态、事件条件、里程碑依赖、分支、效果 | 自动理解任意论文/教材的科学机制 |
| 美术 | 主题联想规范、真实生成记录、新鲜度、操作派生的部件需求 | 内置生图 API、自动分割/自动配准、生成提示等于图片 |
| 动作 | 五个有接触/提交的二维操作，状态/副本/接收绑定 | 任意并行 DAG、全物理仿真、IK、3D |
| 镜头 | 每个已编译操作的实际观察与事件播放 | 任意多镜头导演系统已全部实现 |
| 检查 | 实际 DOM/像素贡献、前后/消融截图、审阅指纹、完整解码 | 自动审美评分、能证明所有遮挡/误导不存在 |
| 输出 | 离线 HTML、H.264 MP4、本地音轨、分层混合 SVG | 纯矢量转换、PPT 内通用交互、自动 TTS/ASR/音乐卡点 |
| 客户流程 | 课程台账、逐条来源、教师签核记录与版本绑定、本地交付清单 | 认证教师身份、学科事实自动正确、已证明学习收益 |

`presentation=interactive` 或 `mechanism.kind` 为连续物理时会明确拒绝当前适配器。不能偷偷切回静态演示。扩展需要领域模型、受限输入、输出状态绑定和实际验证，不是新增一个 action 名称。

合成素材测试用于工程逻辑，不算真实生图、审美、普通 Agent 冷启动或观众实验。未运行项目在 evals 中保留 not_run/not_tested。

历史几何路径仍可在低层工具中诊断和重放；正式 v0.8 export 强制机制/视觉门禁。任何宿主可以另写导出器，因此这些门禁不是安全沙箱，也不保证任意 Agent 永不违背说明。
