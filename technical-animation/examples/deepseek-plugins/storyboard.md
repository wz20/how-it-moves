# 单镜四节拍
|时间|镜头功能与构图|主体动作和尾帧|连续性与风险|
|---|---|---|---|
|0–2s|固定正视全景，三个插卡横排；解释循环也是插件|左到右依次下落插入，落定保持|固定模型/工具/循环次序，插针到达插槽后才变状态|
|2–5s|同一空间，视线下移至 ctx 能力层|注册线路依次延展，抵达后能力接口亮起|模块不换位；下方接口与上方模块一一对应|
|5–8s|保持全景，在工具与循环之间显示协作|橙色调用→工具执行→青绿回执→循环完成|不同方向及文字区分请求/结果；没有循环装饰运动|
|8–10s|原位卸载，空插槽保留以说明变化|工具插件向上退出；8.5秒撤销注册，停留至片尾|只撤销该插件注册，其他模块持续可用；最后1.5秒静止|

声音：无。事件时间线 project.json 是唯一时序源。无品牌片尾，符合已批准的独立机制片段。
