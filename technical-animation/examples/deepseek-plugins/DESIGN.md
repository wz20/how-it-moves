# 视觉与连续性合同
使用 explain-motion comic-lab：暖纸色、粗墨线、橙色动作、青绿回执、黄色循环。
视觉命题：三个独立插件装入同一环境，接通能力后协作，移除一个插件时只撤销其注册。
单镜连续画布，固定正视正交图，无摄影摇移；模块左右始终为模型、工具、循环。所有模块采用同一插卡形态、统一脚针和落点。非写实、无角色。
标题区 x100..1820 y60..220；机制区 x260..1660 y290..810；结论区 y870..980。关键字≥36px。
注册线承载服务可用性；橙色调用包和青绿回执走相同通路相反方向；包抵达后才改变接收状态。
工具卸载用向上拔出、降低饱和度及“已卸载”标签，注册线在卸载完成后撤销；其他模块不换位。
静态关键帧：0秒（未挂载）、4.2秒（能力注册完成）、7.4秒（调用完成）、9秒（卸载清理）。
风险：Amber，主要为调用包与文字遮挡、抵达时序、结尾文字可读性。通过静帧和3秒动作片检查。
