# Comic Lab / 视觉定义

Warm paper stage, high-contrast ink contours, original articulated orange robot and teal test machine. Fixed positions preserve object identity. The activity happens in moving commands and changing machine/context states, not in a carousel of posters.

Palette: paper #F5F0E5; ink #22252B; action #FF7549; observation/success #3CC7B2; decision #FFCF50; error #F06A67.
Type: local Noto Sans CJK SC, PingFang SC or Microsoft YaHei; local monospace for code. No font files distributed. Header ~65px, main object labels ~28px, code 24–30px. English TEST/FAIL/PASS are visual anchors familiar to the target audience.
Motion: jointed head/arms/eyes, wind-up and pointed hand before commands, monotonic Bézier messages, draw-on trace, tool activation after arrival, recoil and observation ingestion, old/new code compare, result badge settling, final settled hold. Camera only on the mechanism layer, stable explanatory text above/below.
Avoid: generic cat, image collage, copied creator avatar, red/green without labels, all elements bouncing, a looping packet after STOP, perspective that makes code unreadable.
